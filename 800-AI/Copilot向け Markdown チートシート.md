
`Codeに切り替えて見てね`
=========================================
Copilot向け Markdown チートシート
=========================================

【基本】

# 見出し

# 大見出し
## 中見出し
### 小見出し

用途:
- 話題の整理
- 目的、背景、課題の分類

-----------------------------------------

- 箇条書き

- 項目1
- 項目2
- 項目3

階層化:
- システムA
  - 機能1
  - 機能2

用途:
- 要件整理
- 課題列挙
- アイデア出し

-----------------------------------------

1. 番号付きリスト

1. 要件定義
2. 設計
3. 開発
4. テスト

用途:
- 手順説明
- 優先順位付け

-----------------------------------------

**強調**

例:
この案件で重要なのは **運用負荷削減** です。

用途:
- 重要点の明示

-----------------------------------------

---

区切り線

用途:
- 指示と本文を分離
- セクションを区切る

-----------------------------------------

コードブロック

開始:
```
終了:
```

例:

```
ここに議事録や文章を貼る
```

用途:
- Copilotへの入力データを明確化
- 指示文と本文を区別

-----------------------------------------

> 引用

例:
> お客様は画面が複雑だと感じている

用途:
- 発言引用
- 要約対象の明示

-----------------------------------------

表形式

|項目|現状|改善後|
|---|---|---|
|工数|10時間|3時間|

用途:
- 比較
- 現状とあるべき姿の整理

=========================================
Copilot依頼テンプレート
=========================================

# 目的
何を達成したいか

# 背景
なぜ必要か

# 課題
困っていること

# 制約
守るべき条件

# 依頼
Copilotにしてほしいこと

-----------------------------------------

例: 要件定義

# 目的
受発注業務を効率化したい

# 背景
手入力が多くミスが発生している

# 課題
作業時間が長い

# 制約
予算追加なし

# 依頼
機能要件と非機能要件を整理してください

=========================================
まず覚える5つ
=========================================

1. # 見出し
2. - 箇条書き
3. コードブロック
4. --- 区切り線
5. **強調**

特に「コードブロックで入力データを囲む」はCopilot利用時の効果が大きい。
